# 💈 Plantilla Web para Barbería y Peluquería

Una plantilla de sitio web ligera, moderna y completamente responsiva, diseñada para barberías, peluquerías masculinas y centros de estética. Incluye integración directa para reservas a través de WhatsApp.

---

## ✨ Características Principales

- **Diseño Moderno y Oscuro:** Estilo elegante adaptado al nicho de las barberías tradicionales y urbanas.
- **100% Responsivo:** Se adapta a dispositivos móviles, tablets y monitores de escritorio.
- **Agendamiento por WhatsApp:** Botones con mensajes predeterminados para coordinar citas de forma rápida.
- **Menú de Servicios y Precios:** Muestra las tarifas y detalles de corte, barba y combos.
- **Fácil de Personalizar:** Construido con CSS nativo mediante variables globales (`:root`) para modificar colores en segundos.
- **Sin Dependencias:** Carga ultrarrápida al no depender de frameworks ni librerías externas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica optimizada para motores de búsqueda (SEO).
- **CSS3:** Flexbox y CSS Grid para la maquetación.

---
